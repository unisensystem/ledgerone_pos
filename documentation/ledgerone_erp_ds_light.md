# FuelingSys ERP — Modern Corporate Design System (LIGHT THEME)

This file contains **ONLY the Light Theme** with fully clarified UI structure, including form layouts, button styles, component anatomy, and screen composition.

---

# 1. Light Theme — Core Visual Principles
- Clean, high-contrast, corporate feel
- White & light-gray surfaces
- Strong blue primary with minimal accents
- Figures, cards, forms must feel "air-light" but strictly aligned

---

# 4. Form UI (Light Theme — WITH CLARITY)
## 4.1 Field Structure
**Label → Input → Helper text (optional)**

### Label
- Font: 13px / 500 weight
- Color: #2F3B4C
- Margin-bottom: 6px

### Input
- Height: 40px
- Padding: 0 14px
- Border: 1.5px solid #D6DBE4
- Background: #FFFFFF
- Radius: 8px
- Focus: border 2px solid #1F7BFF + 2px glow

### Error State
- Border: #E34F4F
- Helper text: #E34F4F

### Disabled
- Background: #F2F4F8
- Text: #9AA1AE
- Border: #E1E4EA

## 4.2 Form Sections
- Section Title: 18px / 600
- Section Spacing: 32px
- Fields per row:
  - Desktop: 3 max
  - Tablet: 2
  - Mobile: 1

## 4.3 Form Actions
- Left-aligned title
- Right-aligned action buttons
- Sticky footer (optional)
